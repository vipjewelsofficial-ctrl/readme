# Clean footer logo

`Gujju-Jewels-Clean-Footer-Logo.png` is the same existing clean logo used by the Version 2 theme's default footer. Its four outer corner areas are uniformly #1D1D1D, matching the theme's footer background. The original lettering and jewellery details are unchanged.

In Shopify, open the theme you intend to use: Customize > Footer > Footer logo (optional replacement). Upload/select this PNG and save. Alternatively, in Version 2, clear that optional replacement selection to use the identical bundled default logo.

Keep the image proportionate with the Desktop logo width and Mobile and tablet logo width controls. This dark-background PNG is intended for the current dark footer. If you use a different footer background, use an original transparent logo asset instead.

No live theme or store setting was changed from this workspace. The Version 2 theme ZIP is unchanged. The faint corner marks visible in the supplied live-site screenshot are absent from this asset; the live site's exact current image could not be fetched from this environment.
