# Theme downloads

The latest version is **Gujju-Jewels-Product-Updates-v3.zip**. It removes the product review integration and replaces the footer image with **VIP JEWELS** text. The footer has editable background, text, heading, button and gradient colours. Related-product counts (1–10), offers, details, benefits, FAQs and native/sticky Add to Cart are retained.

Read [the Version 3 guide](PRODUCT_UPDATES_V3.md). Upload as an unpublished Shopify theme and preview before publishing. Local footer screenshots and checks are under [previews/v3](../previews/v3).

Earlier ZIPs are preserved for rollback. Version 2 included a review-app integration that is removed in Version 3. The original first working download is Gujju-Jewels-Responsive-Product-Theme.zip.

The live store, installed apps and stored customer reviews were not changed from this workspace. Existing theme checker findings and the original malformed global CSS block remain documented in the guide.
