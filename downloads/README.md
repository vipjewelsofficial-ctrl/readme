# Theme downloads

The latest complete theme is **[Gujju-Jewels-Shopify-Editable-v6.zip](Gujju-Jewels-Shopify-Editable-v6.zip)**, based on the uploaded 09 October 2026 evening export. It adds an editable hero slider and connects the audited theme settings to Shopify. Read the [v6 editor guide](../theme-editable-v6/README.md) for upload instructions, setting locations and validation results. All 96 theme files are included.

**Gujju-Jewels-Menu-Theme-v5.zip** is the earlier menu-only package. It includes Home, Necklace Sets, Oxidised Jewellery, Gold-Tone Jewellery, Mangalsutras, Accessories and Shop All in desktop and mobile navigation. Only the header changes and one menu snippet is added; all other 89 files from the uploaded Version 4 export are identical. Read [the Version 5 guide](MENU_THEME_V5.md), create the five linked collections if missing, and upload this ZIP as an unpublished Shopify theme to preview. The Header setting can switch back to any native custom Shopify menu. Menu screenshots are under [previews/v5](../previews/v5).

**Gujju-Jewels-Product-Updates-v4.zip** is the previous complete theme. It replaces Update Cart with up/down quantity arrows and automatic updates on mobile, tablet and desktop. Only three cart files change from Version 3; the VIP JEWELS footer, product pages, related products and other functionality remain unchanged.

If you have made changes in Shopify since installing Version 3, use **Gujju-Jewels-Cart-Only-v4.zip** and apply its three source files through Edit code to preserve those changes. Read [the Version 4 guide](PRODUCT_UPDATES_V4.md). Upload the full ZIP as an unpublished Shopify theme and preview before publishing. Local sample cart screenshots and checks are under [previews/v4](../previews/v4).

Earlier ZIPs are preserved for rollback. Version 2 included a review-app integration that is removed in Version 3. The original first working download is Gujju-Jewels-Responsive-Product-Theme.zip.

The live store, installed apps and stored customer reviews were not changed from this workspace. The earlier packages retain their documented theme checker findings. Version 6 fixes the malformed CSS fragment and reports zero Theme Check errors; an existing unused-snippet warning remains.
