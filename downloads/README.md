# Gujju Jewels theme downloads

Use **Gujju-Jewels-Product-Updates-v2.zip** for the latest theme. Version 2 adds a 1–10 related-product count control, a product review app integration in the store palette, and responsive footer logo controls.

Read [the version 2 setup guide](PRODUCT_UPDATES_V2.md), especially the required review-app setup. Review submissions and moderation require Judge.me or another connected reviews app; no review app has been installed by this repository update.

Upload the ZIP through Shopify > Online Store > Themes > Import theme > Upload ZIP as an unpublished theme and preview it before publishing. The live store has not been changed.

**Gujju-Jewels-Responsive-Product-Theme.zip** is the preserved first working download for rollback. **Gujju-Jewels-v2-Changed-Files.zip** contains the 11 changed/new source paths relative to the original uploaded export, plus instructions, for manual integration.

Local previews and validation reports are under [previews/v2](../previews/v2). Review screenshots use clearly labelled sample app markup; real submissions, moderation and live checkout still require a Shopify preview check.
