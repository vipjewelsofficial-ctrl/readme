# Gujju Jewels updated theme

Download `Gujju-Jewels-Responsive-Product-Theme.zip` and upload it through Shopify > Online Store > Themes > Import theme > Upload ZIP. Preview it before publishing.

Includes responsive offers, description and shipping accordions, service benefits, review summary, related products, FAQs, mobile footer accordions and a mobile sticky Add to Cart button in burgundy and ivory styling.

The ZIP has been verified. This does not update the live store. Configure the advertised promotions separately in Shopify. Existing theme findings and live checkout verification remain outstanding.
