# Homepage spacing update

Use this single file in the existing working theme: `templates/index.json`. Save it through Shopify Edit code by replacing that file's complete contents. It is not a complete theme ZIP.

Eight homepage content sections use 20px top and bottom padding on desktop and 12px top and bottom padding on mobile. The category swipe row uses 12px top and bottom. Combined gaps between the content sections fall from roughly 110–130px to 40px on desktop and from 144px to 24px on phones; tablet behavior follows the existing theme breakpoints.

Only 34 spacing settings change. Every section, order, heading, image, collection selection, product selection, CTA, slider setting and other homepage setting from the retained latest export is preserved. The working product.json and main-product.liquid files are not replaced by this update. No CSS or JavaScript changes. Spacing remains editable in Customize under the relevant section's padding controls.

The file is based on the retained v9.2 homepage configuration. If you have subsequently edited homepage content or blocks, use the equivalent padding controls instead to retain those edits. Set Desktop padding top/bottom to 20; Mobile padding top/bottom to 12 on Shop by Category, New Arrivals, Shop by Style, Shop with Confidence, Trending Picks, What Customers Say, Styled by You and FAQ. In Shop by Category, also set Mobile row padding top/bottom to 12. Hero slider and collection banner have no padding changes.

Reviews are configured but the theme hides the section when it has no review blocks; its empty state remains unchanged. Competitor review and section removal are intentionally reserved for the next step. Native Shopify upload/save and live visual verification remain merchant checks.
